Ghostty 1.4.0
Release notes for Ghostty 1.4.0, released on October 27, 2026.
Ghostty 1.4.0 is a major release that includes large performance and memory improvements, a 100% complete Kitty graphics implementation including animation and relative placements (the first non-Kitty terminal to do so), SSH integration improvements, and hundreds more improvements and fixes across all platforms.
This release features 7 months of work with changes from 172 contributors over 2,889 commits. Thank you to all the contributors, maintainers, community moderators, translators, packagers, and users who each helped make this release possible.
These release notes are painstakingly and lovingly hand-crafted by human Ghostty maintainers, including the full changelog. They take a combined 16+ hours to write, so please enjoy. 🥰
- GHSA-4hwh-wx3w-3fqg. Paste protection didn't treat carriage returns as line endings, so a paste could run a command without confirmation in programs that don't use bracketed paste. This requires user interaction (copy-paste) to trigger.
- GHSA-mhff-mv4q-fp63. Malicious Kitty graphics commands could crash or hang Ghostty, force huge allocations, or in limited cases read or delete files outside the allowed temporary directories. This only requires displaying malicious output.
- GHSA-hcr9-7hcr-mjm8. Malicious terminal output could crash Ghostty, closing every window, via tmux control mode. tmux doesn't need to be installed. This affects Ghostty 1.3.0 and 1.3.1.
- GHSA-hp9c-qp4q-cpw3. The same impact as above, via a tmux control mode layout with a zero-sized or oversized pane. This affects Ghostty 1.3.0 and 1.3.1.
- GHSA-w9q4-5jvv-mcv4.
Clearing the screen into scrollback could corrupt memory if it deleted
the scrollback page holding a styled or hyperlinked cursor. This only
requires displaying malicious output, but only with a small
scrollback-limit such as 0. The default isn't known to be affected.
- GHSA-2r63-vmw6-3m3c.
A crafted directory name could make the zsh shell integration send
arbitrary escape sequences, such as silently replacing the clipboard via
OSC 52. bash was affected in a more limited way. This only requires
cd-ing into a directory from untrusted content, such as a cloned
repository.
- macOS: GHSA-cw69-wm67-5pv8. Cmd-clicking a crafted OSC 8 hyperlink could open unsafe local files or custom URL schemes, leading to arbitrary command execution. Ghostty now blocks unsafe targets and confirms custom URL schemes. This requires user interaction (cmd-click) to trigger.
- macOS: GHSA-mfw9-xcr3-7gfp.
The same issue as above for links detected by the link configuration,
including the default URL matcher. This requires user interaction
(cmd-click) to trigger.
- macOS: GHSA-v8cw-fg4j-jcc4. Drag-and-drop text skipped paste protection, with the same impact as above. This requires user interaction (drag-and-drop) to trigger.
- macOS: GHSA-mxqx-236q-wrv7. Opening a file whose name contains control characters could run a different command than the one shown in the confirmation dialog. This requires a crafted file on your system and confirming the dialog.

PRs: #13943 #13939 #13935 #13934 #13893 #13933 #13389 #13270 #13281
Ghostty now supports Kitty graphics animation and relative placements. These were the last major features of the Kitty graphics protocol that Ghostty didn't support.
Programs that display animated images with the Kitty protocol, such as an
animated GIF shown with kitten icat, now animate in Ghostty instead of
showing a single still frame. Frame transmission, composition, and playback
control are all supported, and animations pause while the terminal isn't
visible. Relative placements let a program position one image relative to
another image's placement, so the child image moves along with its parent.
We also did a full conformance pass against the specification and Kitty itself, fixing dozens of behavioral differences. For example, images now scroll with text inside scroll regions (#4323 ), retransmitting an image ID replaces the old image (#6711 ), and invalid image data now gets an error response instead of silence, which could leave clients hanging. The full list is in the terminal capabilities section.
Kitty graphics are faster, too. Image payloads are now parsed in bulk with SIMD instead of one byte at a time, making large image transfers about 16x faster to parse in our benchmarks (64 MiB of image data, x86_64 Linux), and drawing images costs much less per frame.
Our Kitty graphics implementation now covers 100% of the published specification, making Ghostty (and libghostty) the first terminal to do this outside of Kitty itself.
PRs: #13264 #13473 #13240 #13245 #14130 #14137 #14138 #14017
Ghostty now transparently compresses scrollback that isn't visible, reducing the physical memory those pages use by 70% to 90% for typical text-heavy history. Compression only runs while the terminal is idle and pages are decompressed on demand when you scroll back or search, so it has no measurable impact on I/O throughput.
Thanks to compression, the default scrollback limit has been raised from 10 MB to 50 MB per terminal. On platforms that support compression, a full scrollback still generally uses less physical memory than the old 10 MB limit did.
Note
Compression lowers resident (physical) memory, not virtual memory, so look at resident memory when measuring it. It is currently available on macOS and 64-bit Linux.
Beyond scrollback, memory usage is lower in many places:
- A new, empty terminal now uses about 16 KiB of terminal page memory on macOS, down from 128 KiB in Ghostty 1.3.1.
- On macOS and Linux, memory freed by clearing or trimming scrollback is now returned to the OS instead of being held until the terminal closes.
- Hidden tabs release their GPU resources. On macOS, with one visible tab and 20 hidden tabs, GPU memory dropped from about 385 MiB to 18 MiB. Rebuilding them when a tab becomes visible again takes under a millisecond.

There are performance improvements across the board in Ghostty 1.4 that yield significant gains compared to prior Ghostty versions.
The biggest win came from a surprising discovery: on macOS, the kernel caps every read from a pty at about 1 KiB no matter how large the read buffer is. Previously, Ghostty processed each read as it arrived, so per-read overhead was paid every kilobyte, and the program writing output sat blocked while we parsed. Ghostty now drains the pty on one thread while parsing on another, raising end-to-end I/O throughput by 25% to 55% on macOS (M4 Max, plain and Unicode text) over Ghostty 1.3.x.
VT processing itself is also much faster. In parser benchmarks, plain
ASCII text went from 128 MB/s to 725 MB/s (5.7x), CJK text got 3.4x
faster, and a 2.6 GB dataset of real-world terminal recordings
from asciinema is processed about 25% faster.
Together, these changes took cat-ing a 150 MB text file on macOS from
1.5 seconds to 566 milliseconds.
Other notable improvements:
- Resize: resizing a terminal with a large scrollback is about 6x faster (120x80 with 10,000 lines of scrollback), and 3x to 5x faster with history full of CJK text or emoji.
- Rendering: the renderer holds the terminal lock 2.7x to 11x less per frame, leaving more time for the I/O thread during heavy output.
- Copy and search: formatting terminal contents as plain text, HTML,
or VT, which backs clipboard copy, write_screen_file, and scrollback
search, is 1.5x to 8x faster.
- Launch (macOS): about 15% faster from launch to visible window, and 27% faster to the first rendered frame.
- Idle energy: on macOS, the renderer's display link now sleeps when there's nothing to draw. On GTK, hidden tabs stop rendering, matching macOS.
- Large OSC sequences: OSC 52 clipboard payloads parse about 30x faster, and even short sequences like title changes are about 6x faster.
The GTK app has a new rendering pipeline. It no longer uses GtkGLArea.
Instead, the renderer draws with EGL on its own thread, exports each frame
as a DMABUF, and hands it to GTK to display. Rendering is now
triple-buffered, which should greatly reduce tearing, and no OpenGL calls
run on the main thread anymore, which let us remove a number of
workarounds.
The most visible result is crisp text under fractional scaling. Text and box-drawing characters are no longer blurry with fractional display scaling such as 125% or 150% (#1938 ). We fixed this once before, but it came back after upstream GTK changes. Ghostty now renders at the window's true fractional scale, so every rendered pixel maps to exactly one pixel on screen.
The new render surface needs a system EGL library (see Changes for Package Maintainers). On GPU drivers that can't export DMABUFs, Ghostty falls back to copying frames through the CPU, which is slower but works.
PRs: #13962 #13993 #13995 #13998 #14002 #14061
Ghostty now implements the Kitty clipboard protocol (OSC 5522) on both macOS and GTK. Ghostty 1.3 could parse the protocol but didn't implement it.
OSC 52 can only read and write plain text. The Kitty clipboard protocol lets programs running in the terminal read and write any kind of clipboard data, such as images or HTML, and lets them pick among the formats on the clipboard. Programs can also enable paste events (mode 5522), which tell the program what formats a paste contains so it can read the one it wants. This is how a terminal program can accept a pasted image, for example.
Clipboard access follows the existing clipboard-read and
clipboard-write configurations. By default, reads prompt for permission
and writes are allowed. The permission prompt shows a preview of the
clipboard contents, including images. Programs that send a password can
have your answer remembered for the rest of that terminal session. A new
clipboard-write-limit-bytes configuration limits the size of a single
write (default 64 MiB). A write over the limit fails and leaves the
clipboard untouched.
You can now rearrange splits on GTK by dragging them, matching the macOS feature introduced in Ghostty 1.3. When a tab has two or more splits, each split shows a drag handle at the top. Grab the handle and drop the split onto any other split, including splits in other tabs and windows. An overlay shows which side of the target split it will land on. The terminal contents, working directory, and running processes all move with it.
A new drag-handle configuration controls when drag handles are shown on
both macOS and GTK: auto (default), always, or never. With never,
splits can't be rearranged with the mouse. Hiding the handles was a
common request from users who found them in the way.
On GTK, splits can only be dropped onto other splits. Dragging a split out to create a new tab or window is macOS-only.

Ghostty 1.4 includes dozens of improvements to core terminal emulation. We now run esctest, Thomas Dickey's terminal conformance suite, against Ghostty's terminal core in CI. Alongside that, we fixed many differences from xterm in cursor movement within margins, tab stops, character sets, mode reports, and more. You can find the full list of related changes in the terminal capabilities section.
Ghostty also supports several new sequences, including soft terminal reset
(DECSTR), extended cursor position reports (DECXCPR), backarrow key mode
(DECBKM), and screen size reports in characters (CSI 19 t). Programs can
also now ask whether the terminal is visible using
visibility reports
(mode 2033), so they can stop rendering while hidden.
Keyboard encoding also matches xterm more closely, with fixes for
modifyOtherKeys mode 2 and legacy Alt-as-Escape encoding of non-ASCII
keys.
Two new sequences are disabled by default because they can be abused by untrusted programs, including ones running on a remote machine:
# Allow programs to resize the window (CSI 8 t)
vt-window-resize-allowed = true
# Allow programs to request screen checksums (DECRQCRA)
vt-xt-checksum-report = true
PRs: #12582 #12814 #13533 #13844 #14472 #14854
Ghostty 1.2 introduced SSH shell integration features
as a work in progress. In Ghostty 1.4, they're backed by a new
ghostty +ssh CLI action: a drop-in ssh wrapper that prepares the
remote session for Ghostty and then runs the real ssh with your
arguments forwarded unchanged.
ghostty +ssh user@example.com
# Or alias it so every ssh invocation goes through it
alias ssh='ghostty +ssh --'
Before connecting, +ssh installs Ghostty's terminfo on the remote host
so the proper xterm-ghostty TERM value can be used, and forwards
COLORTERM, TERM_PROGRAM, and TERM_PROGRAM_VERSION. If the terminfo
install fails (for example, tic isn't available on the remote), it falls
back to TERM=xterm-256color. Flags such as --terminfo=false,
--forward-env=false, and --verbose control each step.
The ssh-env and ssh-terminfo shell integration features (still opt-in)
now call +ssh too. Previously, each shell integration carried its own copy
of this logic, which made up roughly a third of our shell integration
scripts. Now bash, zsh, fish, elvish, and Nushell all behave identically,
and you can get the same behavior from scripts or anywhere else by calling
ghostty +ssh directly.
The terminfo install itself is also more reliable. Ghostty now always
installs its own bundled terminfo rather than accepting whatever
xterm-ghostty entry the remote already has, and it reinstalls
automatically when a Ghostty update changes the terminfo. It also no longer
needs infocmp or Ghostty's terminfo on the local machine. Installs are
cached per host and port, so two machines behind one address no longer
share a cache entry. And ssh-env no longer silently overrides SetEnv
entries in your ~/.ssh/config (#11518 ).
The +ssh-cache command that manages this cache now takes positional
destinations (ghostty +ssh-cache user@example.com) and has a new
--prune=30d flag. See the breaking changes if you
script against +ssh-cache.

The vulnerability: CVE-2026-97229 is a critical (CVSS 10.0) vulnerability in how GitLab evaluates regular expressions in CI configuration. One attorney in the case directly compares the DHS-run campaign to the FBI’s infamous Counterintelligence Program, or COINTELPRO, which unconstitutionally surveilled, infiltrated, and blackmailed racial justice, civil rights, and anti-war movements from the 1950s through the early 1970s.
Three former law enforcement officials who reviewed filings concur, telling WIRED that the case is almost certainly part of a wider intelligence-gathering operation that began long before the administration invaded Minnesota in December 2025.
Dueling motions in the case over discovery of DHS’s surveillance program reveal that personnel with Homeland Security Investigations—one of ICE’s two components—repurposed funding mechanisms and investigative tools for serious criminal probes and turned them on domestic dissenters. Operation Keyhole, the HSI undercover program that bankrolled the Minnesota 15 prosecution, dates back to 2008. As of June 2026, it was underwriting a half dozen active undercover investigations in the Minneapolis–Saint Paul area.
Around 120 HSI agents, many drawn from specialized units across the country that have served as the leading edge of the administration’s militarized immigration enforcement operations, were assigned to the case—including 11 undercovers. They used highly invasive surveillance techniques, including the deployment of Reaper drones and Patriot Act tools usually restricted to money laundering and terrorism investigations. Undercover operatives also infiltrated churches in apparent violation of a court order.
The Minnesota 15 indictment stems from the Trump administration’s demand that the Justice Department “go big and go loud” to crack down on community response networks during last winter’s Operation Metro Surge. Twin Cities activists organized volunteers to monitor DHS agents and their vehicles using encrypted Signal groups, homebuilt vehicle databases, and a centralized dispatch system. Government prosecutors claim that this amounts to a criminal conspiracy to block immigration enforcement, unlawfully identify and stalk federal agents, and even assault them.
Their defense attorneys say the heavy charges filed against the Minnesota 15 don’t align with their alleged conduct. “This is the first time I’ve had a client who’s accused of a conspiracy and went on a speaking tour,” says Kevin Riach, who represents defendant Isaac Sant.
Peeking Through the Keyhole
An internal ICE document laying out the scope of Operation Puppet Master—which led to the indictment of the Minneapolis 15—ends by noting, “This case has also been accepted under CUC Op Keyhole.” According to prosecutors, Operation Keyhole is a long-standing program created by HSI’s Saint Paul office to fund “undercover activity”—primarily equipment purchases and personnel costs—in a region covering Minnesota, North and South Dakota, Iowa, and Nebraska. The program has funded at least 77 investigations into “narcotics trafficking, child sexual abuse, financial investigations, and counter-proliferation” since it started in December 2008.
The CUC prefix, per an internal 2008 DHS handbook unearthed by the independent media outlet Unicorn Riot, refers to Certified Undercover Operations, a formal designation with clearly defined oversight mechanisms, procedures, and reporting requirements. Operation Keyhole’s parameters are reviewed every six months by a committee comprising senior DOJ and DHS officials. As of June 2026, when it was last renewed, Keyhole funded six active investigations, including Project Whipple Shield, which was initiated in February to probe claims of assault, stalking, and doxing of DHS agents and other federal employees, and underpins the Minnesota 15 indictment.
At least 11 undercover agents working under Operation Keyhole infiltrated Twin Cities anti-ICE activists, participating in martial arts and know-your-rights trainings, marches, general strikes, and community meetings. They also infiltrated activists’ communications network for identifying possible undercover ICE vehicles and dispatching activists to tail them through the Twin Cities, and penetrated several activist group chats on Signal, transmitting their contents back to other HSI colleagues for analysis and eventual inclusion in the indictment.
Activist conferences as far away as Seattle, Michigan, Chicago, and New York City were placed under surveillance as part of the investigation, and HSI teams photographed and ran the license plates of every car parked in the lot of a meeting location or seen transporting activists. There is also drone footage from unarmed Customs and Border Protection Reaper drones of the activists moving around the Twin Cities area.
The undercovers were part of a much broader group of more than 50 HSI agents, including at least two dozen from HSI’s little-known Special Operations Group, that took part in the investigation and surveillance of the defendants, both digital and in-person. Feds with decades of experience on complex financial crimes, drug cartel investigations, human trafficking, and organized crime were pulled into the Minnesota 15 investigation.
Several of the Minnesota 15 case agents are from out of state and appear in court records for the prosecutions of anti-ICE activists in other cities. This includes Los Angeles–based HSI agents Robert Kurtz III, who specializes in financial fraud, and Ryan Ribner, who allegedly assaulted SEIU California president David Huerta at a June 2025 protest of an ICE enforcement operation, arrested him, and then claimed the then 58-year-old Huerta attacked federal law enforcement. (Huerta’s charges were dropped in July after videos contradicting Ribner’s account surfaced.) HSI records show Ribner was also involved in at least two prosecutions of Southern California residents who physically confronted ICE and Border Patrol agents last year.
Other agents from the conspiracy investigation have also been involved in recent high-profile incidents. Tim Gerber, the “team leader” of an HSI Special Operations Group squad, led the investigation of former CNN host Don Lemon for reporting on a protest at a Minneapolis Church where an ICE agent was a pastor. Fellow SOG agent Yue Her was present at the scene of a 2025 incident when Renee Good’s killer, ICE Special Response Team agent Johnathan Ross, was dragged by the car of a man he tried to apprehend.
“This operation does not seem in any way limited to Minnesota,” says Spencer Reynolds, a former DHS attorney and counterterrorism lawyer who now works at the NAACP Legal Defense Fund. “As we saw with the boots on the ground in the streets, with Greg Bovino leading CBP and Border Patrol special forces units on sweeping raids across the country, this is the intelligence and undercover investigative apparatus that is running in parallel to the door-kicking.”
Follow the Money
Mike German, a retired FBI agent who worked undercover domestic terrorism cases for years before becoming a sharp critic of post-9/11 federal law enforcement, likens the Minnesota 15 case to federal law enforcement’s long history of suppressing left-wing social movements, including the CIA’s Operation MH/Chaos, which surveilled the anti-war movement during the Vietnam War for evidence of foreign influence. One difference is the sheer scale—this time, it’s bigger.
According to a 2011 book by former CIA officer Frank Rafalko, the CIA secret investigation into suspected foreign influence on the New Left and anti-Vietnam War movement had 42 officers working the case at its peak. Court records show 119 HSI agents worked on the Minnesota 15 case alone.
“Broad monitoring of social media, communications, and financial transactions are used to link an ever increasing number of people as potential subjects of investigation and prosecution,” German says. “These are exactly the kind of intelligence activities J. Edgar Hoover adopted to suppress the Civil Rights and anti-war movements in the 1960s.”
The key difference today, German says, is the vast pool of data available to the feds.
HSI used highly invasive measures—including scrutiny of wire transfers, PayPal reimbursements, and other financial transactions; forensic digital analysis of website traffic; 15 terabytes worth of infiltrated Signal chats; and information from a commercial data broker—to identify individuals under investigation.
After a local activist uploaded a license-plate search tool on Fly.io, a developer-focused public cloud platform, to an infiltrated Signal chat, HSI agents reviewed website DNS queries and Stripe data along with data purchased from a commercial broker. This gave HSI access to SSH session logs, outbound connection records, the Fly.io account’s signup IP, and a Stripe card fingerprint on an account that had never completed a payment. Agents fused that with Minnesota DVS records and commercial data from the Thomson-Reuters CLEAR platform to produce a driver's license number, Social Security number summary, years of address history, phone numbers, property records, and jointly registered vehicles.
Documents concerning financial records requested through the Treasury Department’s 314(a) suspicious activity reporting program—created by the Patriot Act to enable speedy tracking of finances for terrorism and money-laundering investigations—show that the feds targeted records of 29 “subjects” during queries conducted on March 31, 2026. Emails viewed by WIRED between several HSI agents based in Los Angeles and Arizona show that batches of records were turned over pursuant to those inquiries, including some dealing with SEIU that a senior Minnesota HSI agent sent to a LA-based colleague to be filed “wherever these records are stored.”
HSI investigators used similar workarounds to warrants and grand jury subpoenas to obtain phone records for several journalists who covered Operation Metro Surge, as first reported by The Guardian. Court records show the feds used an administrative summons request reserved for violations of customs and taxation requirements, which does not fit the activity that made up the criminal charges filed by the Minnesota US attorney against former CNN anchor Don Lemon and others.
The Minnesota 15 case is the clearest example yet of DHS pursuing the Trump administration’s efforts to crack down on what have long been upheld as First Amendment–protected activities. But it’s unlikely alone.
Riach, the defense attorney, says the HSI reports show the agency is complicit in what he called “the new COINTELPRO.”
“What we saw during the immigration surges last year was that ICE is the administration’s paramilitary force, the projector of strength,” Riach says. “Here, we see that HSI are taking the FBI’s place as the investigative secret police—it’s the classic one-two punch of authoritarian regimes around the world.”
